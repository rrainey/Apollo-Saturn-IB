# lib_SaturnIBObliq

The vehicle dynamics and LVDC: C generated by [Obliq-2](https://github.com/rrainey/obliq-2) from `model/saturn_ib_stack.json`, plus a hand-authored modular LVDC rewrite. Older notes call this configuration *Silver*.

| Path | Role | Compiled? |
|------|------|-----------|
| `plant/generated/saturn_ib_stack.{c,h}` | Generated parent plant | Yes |
| `native-snapshots/lvda-lvdc-rewrite/` | **Active** modular LVDC rewrite (`LVDA_LVDC.c` + `lvdc_*.c`) | Yes (default, `LVDC_USE_REWRITE=ON`) |
| `native-snapshots/lvda-lvdc-legacy/LVDA_LVDC.{c,h}` | Legacy hand-edited "golden" `LVDA_LVDC`, kept for A/B comparison | Only when `LVDC_USE_REWRITE=OFF` |
| `plant/generated/LVDA_LVDC.{c,h}` | Generator output for `LVDA_LVDC`, kept for diffing | No |
| `ts/` | TypeScript helpers from the port (AS-205, IGM) | No |
| `artifacts/` | Diagnostic CSV dumps referenced by the notes in `docs/` | No |

The JSON model alone does not reproduce the simulation, because the active LVDC lives in `native-snapshots/lvda-lvdc-rewrite/`. The legacy golden snapshot additionally has hand edits that are not folded back into the JSON.

## Regenerating

The generated parent plant tracks Obliq-2 3.8.5. The segregated subsystem
field in `saturn_ib_stack_t` has moved to its path-qualified name
`Saturn_Instrument_Unit_IU_LVDA_LVDC_LVDA_LVDC`, and `SaturnIBPlantObliq.c`
reads it there.

```bash
OBLIQ_ROOT=/path/to/obliq-2 ./scripts/regen-fullstack.sh               # generated files only
OBLIQ_ROOT=/path/to/obliq-2 ./scripts/regen-fullstack.sh --initialize  # also overwrite the LEGACY snapshot
```

`--initialize` seeds the legacy `native-snapshots/lvda-lvdc-legacy/` snapshot from codegen and is reserved for forensic work on the golden path. The rewrite snapshot is never auto-overwritten.

- Diagram, parameter or gain changes: edit the JSON, regenerate, rebuild.
- LVDC behavior changes: edit the relevant file in `native-snapshots/lvda-lvdc-rewrite/` (`lvdc_igm*.c`, `lvdc_nav.c`, `lvdc_hsl.c`, `lvdc_moverf.c`, …), then rebuild. Each module has a smoke test under `lvda-lvdc-rewrite/tests/` registered with ctest.

## Status

- **Rewrite is the default** LVDC source for saturnib. Promotion landed on branch `lvdc-rewrite`.
- Validation: AS-205 full-boost TMX Appendix C residuals are 25.75 m/s velocity rms / 4507 m position rms (beats legacy golden: 26.55 m/s / 4836 m). See `docs/LVDC_PHASE_D_CLOSURE.md`.
- Toggle: set `-DLVDC_USE_REWRITE=OFF` at configure time to link the legacy golden (`native-snapshots/lvda-lvdc-legacy/LVDA_LVDC.c`). The legacy build no longer uses the full IGM test matrix — it's A/B reference only.

## HSL / J-2 cutoff

The rewrite implements EDD §4.4.2.4 HSL as two-rate (BML math + 40 ms test + 60 ms fire threshold) in `lvdc_hsl.c`. The legacy golden's hand edits are documented in `native-snapshots/lvda-lvdc-legacy/LVDA_LVDC.c` (EDD §4.4.2.4):

- Mode-3 no longer stomps corrected `T_3i` (`Add8`) with open-loop `T3−ΔT`.
- Major-cycle `T3←Add8` inhibited while `nHSLActive≠0` (HSL owns tgo).
- HSL entry requires `T_3i ≤ T_HSL+ΔT_b` **and** vigained `< V_GRD`.
- Cutoff discrete latched; polynomial/40 ms path honors the <20 ms immediate cut.

`SaturnIBPlantObliq_fill_igm_trace` reads IGM state through the rewrite's plant shim (`lvdc_plant_shim.c`): `s_igm_enabled`, `s_T_3_eff_sec`, `s_XS[]`, `s_VS[]`, `s_V_S_mag_mps`, `s_T_HSL_bias_sec`, `s_V_Sg[]`, `s_G_S_prev[]`, `s_hsl_V_*`. Under `LVDC_USE_REWRITE=OFF` the trace reads the legacy's `enable_states` / `signals` struct fields instead; those stay valid because the legacy path still runs the obliq-2–generated conditional subsystem.

**Do not** edit `plant/generated/LVDA_LVDC.*` for LVDC work — the rewrite snapshot is the compile source.
