# lib_SaturnIBObliq

The vehicle dynamics and LVDC: C generated by [Obliq-2](https://github.com/rrainey/obliq-2) from `model/saturn_ib_stack.json`, plus one hand-edited module. Older notes call this configuration *Silver*.

| Path | Role | Compiled? |
|------|------|-----------|
| `plant/generated/saturn_ib_stack.{c,h}` | Generated parent plant | Yes |
| `native-snapshots/lvda-lvdc/LVDA_LVDC.{c,h}` | **Hand-edited** `LVDA_LVDC`, the source of truth for this module | Yes |
| `plant/generated/LVDA_LVDC.{c,h}` | Generator output for `LVDA_LVDC`, kept for diffing | No |
| `ts/` | TypeScript helpers from the port (AS-205, IGM) | No |
| `artifacts/` | Diagnostic CSV dumps referenced by the notes in `docs/` | No |

The JSON model alone does not reproduce the simulation, because `LVDA_LVDC.c` has hand edits that have not been folded back into it.

## Regenerating

The generated parent plant tracks Obliq-2 3.8.4. The segregated subsystem
field in `saturn_ib_stack_t` has moved to its path-qualified name
`Saturn_Instrument_Unit_IU_LVDA_LVDC_LVDA_LVDC`, and `SaturnIBPlantObliq.c`
reads it there.

```bash
OBLIQ_ROOT=/path/to/obliq-2 ./scripts/regen-fullstack.sh               # generated files only
OBLIQ_ROOT=/path/to/obliq-2 ./scripts/regen-fullstack.sh --initialize  # also overwrite the hand edits
```

- Diagram, parameter or gain changes: edit the JSON, regenerate, rebuild.
- HSL, late-cutoff or other LVDC changes: edit `native-snapshots/lvda-lvdc/LVDA_LVDC.c`. Do not pass `--initialize` unless you mean to discard those edits.
